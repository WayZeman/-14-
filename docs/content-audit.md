# Редакційна карта контенту 14 ОРБ

Оновлено під час аудиту тавтології та дублювання. **Джерело UI-текстів:** `src/content/site-copy.ts`. **Перевірені факти та контакти:** `src/lib/site-config.ts`.

## Ролі секцій (головна)

| Секція | Питання, на яке відповідає | Рішення |
|--------|---------------------------|---------|
| Hero | Хто ми, перше враження | Залишити headline; sub — про цінність інформації, не про «технології» |
| Хто ми (#about) | Офіційна формула + роль розвідки | Офіційний абзац **один раз** (`aboutOfficial`); далі — унікальні p2/p3 з `homeAbout` |
| Напрямки | Що робить кожен напрям | Унікальні картки в `siteCopy.directions.items`; без повтору hero/about |
| Рекрутинг | Які посади відкриті + базові вимоги | Тільки `requirementsOfficial`; переваги — лінк на `/join` |
| Як долучитися | Схема контакту | Кроки без дублю FAQ |
| Новини | Що нового | Прев’ю з БД; empty state без повтору support |
| Підтримка (блок) | Куди переказати | Коротко; деталі — `/support` |
| Final CTA | Як зв’язатися | Без повтору слogan «дій першим» |

## Сторінки

| Сторінка | Унікальна роль | Було / стало |
|----------|----------------|--------------|
| `/join` | Форма + переваги + FAQ | H1 «Звернення до рекрутера»; `benefitsOfficial` лише тут |
| `/vacancies` | Каталог посад | Окремий intro; не копіює recruiting |
| `/support` | Реквізити та кампанії | H1 «Збори та реквізити» (≠ home block) |
| `/about` | Повний текст з CMS | Fallback — `aboutOfficial` |
| `/history` | Хронологія | Джерела в seed; потребує погодження |

## Виявлені повтори (усунено)

- «Очі і вуха… технологіям…» — лише `aboutOfficial` + seed about (розширена сторінка).
- `benefitsOfficial` — прибрано з home recruiting; лишено на `/join`.
- Однакові заголовки підтримки — home «Допомога підрозділу», support «Збори та реквізити».
- Tagline на hero + підпис на фото about — підпис замінено на `imageCaption`.
- Чотири однакові `requirements` у seed — унікалізовано за посадою.
- FAQ join — централізовано в `siteCopy.joinFaq`.

## CTA

| Місце | Текст | Призначення |
|-------|-------|-------------|
| Hero | Приєднатися / Про підрозділ | `/join`, `/#about` |
| Footer | Залишити звернення | `/join` |
| Directions | Переглянути вакансії | `/vacancies` |
| Join steps | Перейти до форми | `/join#form` |

## Автоперевірка

```bash
npm run content:check
```

Звітує про однакові рядки (≥24 символів) у різних файлах `src/`. Allowlist: назви, навігація, офіційні повтори.

## Потребує погодження з батальйоном

- Дати в `/history` (seed: березень 2022, серпень 2025) — Wikipedia/MilitaryLand.
- Формулювання `benefitsOfficial` — з архіву сайту, граматика оригіналу збережена.
- Експерimental hero headline — залишено за `useExperimentalHeadline`.
- Існуючі записи в Neon (about, vacancies) **не** оновлюються seed — потрібна правка в адмінці або окремий migration script.
